# 🍕 Maven Pizza Sales Analytics & Operations Dashboard

[![Power BI](https://img.shields.io/badge/Power_BI-Operations_Dashboard-F2C811.svg?style=flat&logo=powerbi&logoColor=black)](https://powerbi.microsoft.com/)
[![DAX](https://img.shields.io/badge/DAX-Data_Analytics-blue.svg)](https://learn.microsoft.com/en-us/dax/)

A Power BI Business Analytics Dashboard evaluating restaurant sales revenue, ordering volume, peak business hours, and pizza category performance for Maven Pizza.

---

## 🌟 Key Operational Insights

- **Revenue & Order Trends**: Tracking total revenue, average order value, and total pizzas sold.
- **Peak Hour Heatmap**: Pinpointing busiest day-of-week and hourly windows to optimize kitchen staffing.
- **Product Categorization**: Analyzing top-performing pizza types (Classic, Supreme, Veggie, Chicken) by sales volume and size.

---

## 🛠️ Tech Stack

- **Platform**: Microsoft Power BI Desktop
- **Language**: DAX, Power Query
